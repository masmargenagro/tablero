# MARGEN AGRO · Tablero del productor

Tablero público con indicadores del agro: pizarra de Rosario, dólar, futuros A3, Chicago, hacienda de Cañuelas y comparadores para el productor.

- `index.html`: la página.
- `datos.json`: los valores. Se actualiza los días hábiles; la página lo lee al abrir.
- El dólar se consulta en vivo al abrir la página; si la consulta falla, se muestran los valores de `datos.json`.

Valores de referencia publicados por las fuentes indicadas en cada bloque. No constituye recomendación comercial.
